Scoreboard camera (ScoreSight)

NO DATA YET

ScoreSight reads the scoreboard from a camera and sends the numbers here. No extra software and no serial cable, and it works with any scoreboard.

Set up ScoreSight
  1. In ScoreSight, name your boxes the usual way: Home Score, Away Score, Time, Period, Shot Clock, Home Fouls, Away Fouls, Home Timeouts, Away Timeouts. For football you can add Down, To Go, Ball On, and Home Possession / Away Possession.
  2. Open the API tab and check Send out API requests to external services.
  3. Paste the feed URL above. Encoding: JSON (Simple key-value). Method: POST.
  4. Set the rate to 2 requests per second and leave Only changes off, so the scorebug can tell when the clock stops.
  5. Watch the table below fill in, then check Send ScoreSight readings to the scorebug.

Scoreboard controller (serial)

NOT CONNECTED

Connect the press-box scoreboard controller's serial output to this computer with a USB-to-RS232 adapter, then pick the port. Works in Chrome or Edge on a laptop. Keep this tab open while it runs.

Last frame

Bytes that changed in the last few seconds are highlighted. Run the clock on the controller to find it.

Field mapping

Map each scoreboard value to a byte offset (0 = first byte of the frame). Only mapped fields are sent, and only when the controller changes them, so manual corrections stick until the next change.
